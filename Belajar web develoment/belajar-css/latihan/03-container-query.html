Satu viewport, dua lebar wadah.

Kedua kartu menggunakan class yang sama. Perbedaannya datang dari lebar container masing-masing. Gunakan jendela cukup lebar agar perbedaannya terlihat.

Browser mengenali container-type. Saat isi wadah minimal 32rem, kartu berubah menjadi dua kolom.

Jika browser tidak mengenali container-type, kedua kartu tetap satu kolom dan semua isi tetap tersedia.
