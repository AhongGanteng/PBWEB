Bandingkan distribusi ruang Flexbox dan Grid.

Ubah lebar jendela agar jumlah item per baris berubah. Perhatikan baris terakhir. Kontrol di bawah mengubah Flexbox; Grid tetap sebagai pembanding.

Flexbox

Satu — isi pendek
Dua — isinya sedikit lebih panjang
Tiga
Empat — amati lebar item di baris terakhir
Lima

Setiap baris Flexbox membagikan ruangnya sendiri. Basis item: 12rem, grow: 1, shrink: 1.

Grid

Satu — isi pendek
Dua — isinya sedikit lebih panjang
Tiga
Empat — kolom mengikuti track bersama
Lima

Item mengikuti track yang sama. Kolom pada baris berbeda tetap selaras.

Tugasmu

  1. Tambahkan item keenam pada kedua contoh. Kapan perbedaannya lebih sulit terlihat?
  2. Ganti basis Flexbox dari 12rem menjadi 18rem. Prediksi perubahan jumlah item per baris.
  3. Ganti Grid menjadi tiga kolom eksplisit, lalu uji di layar sempit. Perbaiki dengan media query.
