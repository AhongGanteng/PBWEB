Daftar latihan

Sebuah request bisa punya beberapa hasil.

Contoh memakai file JSON dalam paket yang sama. Tidak ada akun atau API eksternal yang dibutuhkan.

Jalankan folder paket melalui server HTTP lokal. Contoh: python3 -m http.server 8000 --bind 127.0.0.1, lalu buka http://localhost:8000/. Fetch pada file:// tidak dipakai di latihan ini.

Pilih skenario, lalu muat.

    Tugasmu

    1. Bandingkan sukses kosong, HTTP 404, dan bentuk data yang salah.
    2. Gunakan network throttling di DevTools untuk melihat loading dan mencoba Batalkan.
    3. Tekan Muat lagi saat request lambat dan periksa mengapa hasil lama tidak menimpa yang baru.
